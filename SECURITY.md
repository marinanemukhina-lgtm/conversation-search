# Security

Experimental local CLI, not production-ready or security-audited. Do not expose it as a network service. Run the synthetic demo first. Do not commit private archives, databases, raw connector responses, tokens or logs.

Imports enforce bounded inputs and validate ZIP members before a transaction; tests are not a guarantee against every malicious input. Source text is treated as data, never as executable instructions.

For public bug reports use only synthetic reproductions. Do not disclose secrets or real conversation contents in issues. No private vulnerability-reporting channel or response SLA is promised by this repository.
